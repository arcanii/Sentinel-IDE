SQLTerminal-Win32
-----------------
Sentinel-IDE's Win32 shell derives from SQLTerminal-Win32 (same author), which is
licensed GPL-3.0. The dark/coral palette in src/host/win32/Theme.h, the themed
dialog conventions, the tree/splitter handling, and the worker-thread build model
all originate there. This is why Sentinel-IDE is GPL-3.0-or-later rather than a
more permissive licence.

src/editor/EditorModel.{h,cpp} is VENDORED from that project (its
src/editor/EditorModel.{h,cpp}) rather than merely derived from it: the pure,
platform-free text model behind its Direct2D/DirectWrite editor. It is copied
essentially verbatim, with one behavioural change and one addition, both marked in
the source: the word-class predicate is Sentinel's `iswalnum(c) || c == '_'`
instead of SQLTerminal's ASCII-only [A-Za-z0-9_], so word navigation agrees with
Sentinel's own tokenizer; and `textCrlf()` was added for the on-disk CRLF form.
Same author, same GPL-3.0 licence, so no licence conflict arises.

src/host/win32/D2DSupport.h is likewise VENDORED from that project (its
src/ui/D2DSupport.h) — the shared Direct2D/DirectWrite factory helpers behind the
same editor. Its code is byte-identical but for one change: `namespace sqlterm`
becomes `namespace sentinelide`.

src/host/win32/D2DEditor.cpp is DERIVED from that project's
src/ui/SqlEditorControl.cpp rather than vendored: the device-resource lifecycle,
clipboard, word selection, caret blink, IME positioning, surrogate-pair buffering
and mouse-autoscroll code are carried over close to verbatim, while the layout,
geometry and scrolling are written fresh, because SQLTerminal's editor word-wraps
one whole-document text layout and a code editor must not. The provenance of each
part is recorded in that file's header comment.


Appcast format
--------------
The auto-update feed follows the Sparkle appcast XML namespace
(http://www.andymatuschak.org/xml-namespaces/sparkle), originally from the Sparkle
project for macOS. The format is used here for interoperability with WinSparkle; no
Sparkle code is included in this repository.
